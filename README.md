# Titanic Survival Prediction - Business Analytics Project

Kaggle Public Score: 0.8433

## Project Overview
This project predicts passenger survival on the RMS Titanic using machine learning techniques. 
From a business analytics perspective, the analysis provides insights into customer segmentation, risk assessment, and priority systems in emergency situations.

## Business Insights
- Gender and age were the strongest predictors of survival.
- Higher socio-economic status (Pclass and Fare) significantly improved survival probability.
- Traveling with a small family increased chances of survival.
- These patterns offer valuable lessons for insurance, hospitality, and crisis management.

## Methodology
- Data Preprocessing: Handled missing values using grouped medians for Age and Fare.
- Feature Engineering: Created Title, FamilySize, IsAlone, HasCabin and other features.
- Models: Random Forest and XGBoost with ensemble methods.
- Validation: Used cross-validation to ensure model robustness.

Best Validation Accuracy: 84.33%

## Results
- Kaggle Public Score: 0.8433
- Strong performance on key business-related variables (Sex, Pclass, Title).
