# Titanic Survival Prediction - Business Analytics Project

Kaggle Public Score: 0.8433

## Project Overview
This project predicts passenger survival on the RMS Titanic using machine learning. 
From a business analytics perspective, it provides insights into customer segmentation, risk assessment, and priority systems in emergency situations.

## Business Insights
- Gender is the strongest predictor: Female survival rate is much higher than male.
- Passenger Class shows strong socio-economic effect.
- Age and family status also play important roles.

## Business Applications (International Business Perspective)
- Companies can design better priority systems in crisis situations.
- High-value customers (higher Pclass/Fare) deserve premium service.
- Customer segmentation based on vulnerability can improve retention and risk management.

This analysis combines technical machine learning with actionable business strategy.

## Methodology
- Data Preprocessing: Handled missing values using grouped medians.
- Feature Engineering: Created Title, FamilySize, IsAlone, HasCabin.
- Models: Random Forest and XGBoost ensemble.
- Validation: Cross-validation for robustness.

## Results
- Kaggle Public Score: 0.8433
- Strong performance on key business-related features (Sex, Pclass, Title).

## Technologies Used
- Python, Pandas, NumPy
- Scikit-learn, XGBoost
- Jupyter Notebook
